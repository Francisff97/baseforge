# BaseForge — platform info

Public metadata and images for **BaseForge**, a platform that lets Base Builder communities sell packs and coaching sessions online.

- `platform.json` — platform and developer information shown inside BaseForge installations
- `image/` — avatars and screenshots referenced by `platform.json`
